# Customer Service Chatbot V2

A separate, lightweight browser chatbot for basic customer-service questions. This project does not replace the original `customer-service-chatbot` folder.

## Run it

Open `index.html` in a web browser. No installation, server, or API key is required.

## Supported questions

- Order tracking
- Refunds and returns
- Payment issues
- Password and account access
- Contacting a support agent

The chatbot uses direct phrase matching plus keyword scoring and provides a clear fallback when it cannot identify a request.
